# До первого публичного выпуска

Обновлено 28 сентября 2026. Рабочий локальный demo flow уже завершён:
реальные captures desktop/mobile, versioned baseline и tolerance, pixel diff,
browser evidence, link checks, история и URL отчётов, recovery и обычные retries.
CI проверяет весь путь на Linux. Это ещё не публичный сервис.

Приоритет оставшейся работы:

1. Доступ: GitHub login/сессии и владение ресурсами для режима с пользовательскими
   данными. Owner-only OAuth, сессии, owner gate и UI реализованы. Нужны OAuth App credentials
   и реальный прогон; текущий workspace единственный, без multi-user регистрации.
2. Среда runner: supervisor завершает зарегистрированный Chromium при сбоях.
   Контейнерную изоляцию и ограничения сети ещё нужно реализовать. До этого разрешён
   только controlled fixture; запрет произвольных URL сохраняется при публикации.
3. Hosting: измерить потребление, подготовить конфигурацию, секреты, миграции,
   storage и резервное копирование. Платные ресурсы согласовать по конкретной смете.
4. Проверка пользователем: один короткий сценарий original → baseline → regression
   → evidence → approve → repeat на опубликованном preview.
5. Упаковка: README с актуальными снимками, архитектурой, ограничениями, demo-видео
   и рассказом о принятых решениях. Внешняя проверка и исправления.

Не расширять объём ради календаря: дополнительные размеры, AI-функции и crawler
не нужны для первого выпуска. Batch нескольких страниц остаётся отдельным объёмом
с PageResult и частичными результатами; текущий Run проверяет одну страницу/размер.

Возможный быстрый промежуточный выпуск — публичная витрина сохранённых отчётов,
без запуска runner и мутаций. Она пригодна для демонстрации портфолио, но не заменяет
авторизацию и изоляцию рабочего сервиса. Решение о таком формате пока не принято.
