# Технические решения

Решения на 24 сентября 2026 года; пересматриваются при конкретной проблеме,
а не ради добавления технологий в резюме.

| Решение | Причина | Компромисс |
| --- | --- | --- |
| React + Vite | Знакомый пользователю стек; основной продукт — интерактивный кабинет | SSR/SEO лендинга решаем позже отдельно |
| TypeScript во всех приложениях | Общие контракты и безопасный рефакторинг | Внешние данные всё равно требуют runtime-валидации |
| Node.js 24 LTS | Единый runtime разработки и CI | Текущий default Node 20.15.1 нужно заменить для проекта |
| Fastify API | Явная HTTP-граница и отдельный жизненный цикл от браузеров | Нужны собственные auth и deployment wiring |
| PostgreSQL + Graphile Worker | Данные и очередь в одной транзакции; меньше инфраструктуры | At-least-once требует идемпотентных задач |
| Drizzle + SQL migrations | Типизированные запросы и видимая схема | Миграции и ограничения проектируем явно |
| Отдельный worker и изолируемый runner | Браузерная нагрузка и внешние сайты отделены от HTTP API | Сложнее локальный запуск и деплой |
| Polling активного Run | Достаточно для небольшого числа запусков | Прогресс приходит с задержкой до нескольких секунд |
| PNG diff с подтверждённым baseline | Понятный результат с проверяемым доказательством | Требует стабильной среды, масок и настройки порога |
| Chromium и два viewport | Реалистичный объём на месяц | Это не полная кроссбраузерная или мобильная проверка |
| npm workspaces | Достаточно для трёх приложений и общих пакетов | Команды сборки первоначально задаём явно |

## Вопросы, которые решаем позже

- Визуальное направление: после двух прототипов отчёта и ответа пользователя.
- Hosting и бюджет: после измерения времени и памяти одного Run.
- Провайдер S3: после выбора hosting; интерфейс хранения не зависит от него.
- Точные версии библиотек: при scaffolding с lockfile и проверкой совместимости.
- Порог diff и объём хранения: после эксперимента на fixture.

Не добавляем Redis, Kubernetes, отдельные микросервисы для каждого вида проверок
и AI-функции в первоначальную архитектуру: в текущем объёме у них нет задачи.
