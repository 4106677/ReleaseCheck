## Что можно попробовать

- Переключить направление A/B в верхней панели.
- Перетаскивать границу before/after непосредственно по изображению или ползунком.
- Переключить Baseline, Current и Difference.
- Выбрать visual / JavaScript / network issue и прочитать его контекст.
- Открыть Review summary; закрыть мышью или Escape.
- Проверить мобильную ширину: сравнение расположено перед очередью замечаний.

Клавиатура: кнопки и ползунок доступны через Tab, стрелки двигают ползунок,
summary использует native modal dialog с удержанием фокуса и Escape.

## Граница прототипа

Это демонстрационный отчёт с фиксированным ID. Кнопка summary ничего не принимает
и не меняет baseline. Две browser issues в макете — JS-ошибка и HTTP 404;
дублирующее console-сообщение про тот же 404 не показано отдельной проблемой.
Рабочий отчёт теперь группирует HTTP/console только при подтверждённом совпадении
URL и status, сохраняя оба исходных наблюдения в Original evidence.

Пакет checks теперь умеет сравнивать PNG с одинаковым профилем захвата. Он
возвращает matched/changed, число и долю отличающихся пикселей и diff PNG.
Несовместимые профили/размеры не сравниваются; некорректные пороги и изображения
отклоняются. Профиль включает браузер, OS release, platform, architecture,
viewport и фиксированные параметры рендера. Сохранение baseline и автоматический
вызов сравнения из worker подключены в рабочем Release Console.

## Обновление материалов

При работающем fixture и собранных пакетах:

```sh
npm run design:assets
npm run test:design
```

`design:assets` заново снимает исходную и изменённую страницы и создаёт PNG и
metrics.json. При изменении OS/browser профиль изменится; не заменяйте только
один скриншот без второго. `test:design` проверяет обе схемы, мышь/клавиатуру,
смену режимов и мобильную ширину. Снимки проверки лежат в `.local/design-review`.

Release Console перенесён в живой отчёт; просмотрщик изображений общий с прототипами.
В рабочем отчёте показываются группы и число исходных observations; каждый источник
доступен в Original evidence. Старые данные без контекста не объединяются по догадке.
